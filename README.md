## 🗂️ Módulos

| Módulo | Descripción |

| `contabilidad` | Contabilidad general y reportes |
| `control-volumetrico` | Control de traslados y autoconsumo de combustible |
| `cotizador` | Generación de cotizaciones |
| `cuentas-por-pagar` | Gestión de cuentas por pagar |
| `edi` | Intercambio electrónico de datos |
| `facturacion` | Emisión y gestión de facturas |
| `indicadores` | KPIs y métricas operativas |
| `informes-gerenciales` | Reportes para toma de decisiones |
| `inventarios` | Control de inventario y activos |
| `llantas` | Gestión y mantenimiento de llantas |
| `mantenimiento` | Mantenimiento preventivo y correctivo |
| `nomina` | Cálculo y gestión de nómina |
| `operacion-portuaria` | Operaciones en puertos |
| `paqueteria` | Gestión de envíos y paquetería |
| `planeacion-solicitudes` | Planeación y solicitudes internas |
| `trafico` | Control de tráfico y rutas |
| `trasporte-personal` | Transporte de personal |
